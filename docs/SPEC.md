## Мета і принципи
Cellwise (у сторах — «Cellwise: Sudoku Logic», ID застосунку app.sudokucell.cellwise) — офлайн-судоку для iOS і Android, яке заробляє на рекламі та разовій покупці «Remove ads». Увесь інтерфейс — англійською.
- Аудиторія: казуальні гравці 13+, застосунок не позначаємо як дитячий (Families policy).
- Офлайн: пазли вбудовані, прогрес на пристрої, бекенду в MVP немає.
- Реклама не заважає грі: нічого посеред партії, повноекранна — тільки після завершеної гри.
- Без ігрової валюти (коїнів, кристалів) у MVP: rewarded-реклама дає конкретну дію — підказку або друге життя.
- Чим виділяємось: «паперовий» дизайн (сітка й нотатки як на папері), чесні рівні складності, щоденний виклик зі стріками (v1.1), підказки з поясненням техніки (v1.1).

## Ігрова логіка
Пазли з банку, згенерованого скриптом заздалегідь. Складність = найскладніша потрібна техніка.

| Рівень | Техніки |
| --- | --- |
| Easy | Naked та hidden singles |
| Medium | + naked/hidden pairs, pointing pairs |
| Hard | + triples, box/line reduction, X-Wing |
| Expert | + XY-Wing, Swordfish, ланцюжки |

- Генератор (Node/TS у `tools/generator`): повна сітка → видалення цифр із перевіркою єдиного розв'язку → оцінка рівня «людським» солвером.
- Банк: по 2000 пазлів на рівень, JSON (пазл + розв'язок по 81 символу), близько 1,4 МБ.
- Рушій (чистий TS, без React, з тестами): стан сітки, нотатки, undo, конфлікти, завершення.
- Підказка: MVP — правильна цифра у вибраній клітинці; v1.1 — наступний логічний крок і назва техніки.
- Збереження (MMKV): партія після кожного ходу, статистика, налаштування, зіграні ID пазлів.
- Підказки й друге життя йдуть через модуль-«гаманець» (balance / earn / spend), щоб пізніше можна було додати коїни.
- Щоденний виклик (v1.1): пазл дня детерміновано з банку за датою.

## Монетизація
| Формат | Де | Правило |
| --- | --- | --- |
| Rewarded | Hint, Second chance | Тільки за вибором гравця; кнопка неактивна, поки оголошення не завантажене |
| Interstitial | Між завершеною сіткою та екраном перемоги | Не в перших 2 партіях; раз на 3 партії й не частіше ніж раз на 3 хв; передзавантаження |
| Banner (adaptive) | Головний, статистика; на ігровому екрані в MVP немає | Не впритул до кнопок |
| App open | — | Не використовуємо |

- «Remove ads»: non-consumable через RevenueCat; прибирає банери й interstitial, rewarded лишається; обов'язкова кнопка «Restore purchases».
- Ігрової валюти в MVP немає. Якщо пізніше знадобиться — RevenueCat virtual currency + невеликий серверний ендпоінт для списання.
- Remote Config: `interstitial_first_after_games`=2, `interstitial_every_n_games`=3, `interstitial_min_interval_sec`=180, `banner_on_game_screen`=false.
- До релізу — тільки тестові ID оголошень.

## Технічний стек
Expo (React Native) + TypeScript, expo-router, Zustand (persist у MMKV), react-native-mmkv, reanimated + expo-haptics, react-native-google-mobile-ads (AdMob + AdsConsent/UMP), RevenueCat, Firebase (Analytics, Crashlytics, Remote Config), Jest (jest-expo), EAS Build/Submit. Тестування через development build (не Expo Go). Локалізація: у MVP лише англійська; рядки в одному файлі. Сайт для privacy policy та app-ads.txt — WordPress.

## Дизайн
Паперовий стиль: теплий папір, чорнильні лінії сітки, задані цифри — серифом Literata, введені — «чорнильно-синім» (#2B4C8C), помилки — червоним олівцем з хвилястим підкресленням, виділення — маркером. Інтерфейс — Inter. Клавіатура 3×3 (повторює блок, кнопки ≥ 44 px). Після 3 помилок — шторка знизу поверх гри. Токени — у CLAUDE.md.

## Реліз і вимоги сторів
- Google Play: $25 разово; для нового особистого акаунта закритий тест 12+ тестувальників 14 днів поспіль (набрати 15–20); потім production access.
- Apple Developer Program $99/рік, TestFlight, App Store review.
- Privacy policy та app-ads.txt на сайті розробника.
- UMP-форма для ЄЕЗ/UK (AdMob → Privacy & messaging); iOS ATT + `NSUserTrackingUsageDescription`, SKAdNetwork ID.
- Аудиторія 13+; Data safety (Play) і App Privacy (Apple).
- Target API level за чинною вимогою Google Play.
- Сторінки в сторах: назва «Cellwise: Sudoku Logic», опис англійською, іконка, 4–6 скриншотів.
